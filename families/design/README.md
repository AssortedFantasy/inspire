# Design artifacts

Thirty-two procedural leaves produce concrete artifacts with explicit constraints:

- `circuits`: twelve SPICE netlist topologies, organized by passive component
  system or amplifier topology. Each topology has equal probability within the
  circuit branch; ancestor weights match topology counts. Electrical tests solve
  the emitted circuit independently, beyond connectivity checks.
- `wardrobe`: sixteen occasion/weather contexts, with curated compatible layers
  and realized palettes. Generic textile vocabulary comes from a checksum-pinned,
  reviewed CC0 Corpora subset; styling and suitability rules are original.
- `textiles/weaving`: four executable rising-shed lift-plan families, with threading,
  color repeats, every shed, and a complete drawdown. Tests check cyclic floats and
  interlacement, not just matrix formatting.

The three artifact systems have equal local weight. Occasion and weather are
balanced within wardrobe; the four weave families are balanced within weaving.
The former mixed `design/circuits` and `design/wardrobe` paths remain selectable
as branches. Leaf READMEs and branch source notes explain model scope and reuse
terms. Development-time rebuild/import scripts make no runtime network requests.
