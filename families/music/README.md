# Music

`chart-titles/` contains the first 30 entries of Billboard's published 1959
year-end Hot 100: title, credited performer, year, and rank. These are historical
chart positions, not an all-time ranking or a list of every 1959 release.

Metadata was checked on 2026-10-13 against the linked Wikipedia transcription,
revision 1368373981. It identifies the original chart as *The Billboard*,
December 14, 1959, page 78, covering January–November weekly charts. The linked
primary scan returned HTTP 403, so verification used the transcription, not the
scan. Both links and that limitation appear in each record's provenance.

Only factual metadata and original framing are included. No song lyrics,
recordings, artwork, or reviews are reproduced.
