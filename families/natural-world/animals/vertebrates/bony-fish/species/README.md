# Bony fish species

599 named GBIF Backbone species across 229 source families and 36 orders.
Stable GBIF IDs, source classification, recorded habitat categories and available
English names come from the pinned taxonomy snapshot. The first API page per
order and three-species cap per family make this a breadth sample, not an
inventory or a claim of current taxonomic consensus.

289 records retain exact-binomial FISHMORPH v1.1 `MBl` matches: maximum body
length in centimetres, compiled from FishBase (Froese & Pauly 2020). The source
does not specify standard, total or fork length. These are compiled source
values, not claims of current maxima. Missing values are omitted. Specimen-image
measurements belong to a separate sibling leaf.
