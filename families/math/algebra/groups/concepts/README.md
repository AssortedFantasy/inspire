# Group theory facts

Forty canonical equations, presentations, and concrete examples cover group
structure, homomorphisms, quotients, actions, automorphisms, and finite-group
theorems. Stable IDs and source provenance are retained. Text contains factual
mathematical notation rather than original explanations or paraphrased prose.

Reference context: J. S. Milne, [Group Theory](https://www.jmilne.org/math/CourseNotes/GT.pdf),
version 4.01, title-page date 6 November 2025, originally consulted 13 October
2026. No reference prose, exercises, or PDF content is redistributed.

Finite-group hypotheses remain explicit. Quotient examples name normal
subgroups; permutation equations apply the right factor first. Modular orders,
kernels, conjugation, commutators, Sylow counts, subgroup orders, and group orders
were checked independently. JSON retains the three-field schema and unique IDs.
Records are sampled uniformly within the leaf.
