# Groups

`concepts` retains the existing 40 group-theory records. `finite-groups` contains
seven procedural leaves with independently selectable constructions.

The generators emit focused calculations and finite objects: subgroup orbits,
quotient maps, multiplication tables, polygon actions, conjugacy classes,
permutation products, affine orbits, and matrix powers. A sample chooses one
view instead of repeating a group's entire definition and invariant list.

The constructions are implemented directly from modular arithmetic, permutation
composition, and matrix multiplication. Tests check algebraic invariants and
computed structural claims. No dataset or reference prose is embedded in the
procedural leaves. Mathematical background:
[J. S. Milne, Group Theory](https://www.jmilne.org/math/CourseNotes/GT.pdf).
