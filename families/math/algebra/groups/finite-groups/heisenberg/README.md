# Finite Heisenberg groups

Upper unitriangular 3×3 matrices over F_p for p ∈ {2,3,5,7,11,13}.
Four views emit matrix products, a commutator, a conjugacy class and centralizer
size, or successive powers and an inverse. Characteristic two includes elements
of order four.

Tests exhaust group axioms and independently check matrix multiplication for
p=2,3. Every supported element is checked for its inverse, minimal order, and
center membership. Tests also verify commutators and conjugacy classes.
Fixed seeds check all six fields and reproducibility.
