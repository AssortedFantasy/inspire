# Finite groups

Seven procedural leaves cover cyclic groups, direct products of cyclic groups,
dihedral groups, generalized quaternion groups, symmetric groups, affine groups
over prime fields, and finite Heisenberg groups.

Each leaf chooses among several focused artifacts. Products, actions, orbits,
subgroups, and conjugacy calculations appear separately. Dihedral D_n has order
2n; quaternion Q_n has order n, with presentations resolving the notation.

All work is bounded and offline. Tests check group laws, inverses, minimal
orders, action conventions, and the additional structural calculations.
See the leaf READMEs for parameter bounds and coverage.
