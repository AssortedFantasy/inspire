# Direct products of cyclic groups

Two to four factors C_n with 2 ≤ n ≤ 16. Four views emit coordinate arithmetic,
a k-torsion subgroup, a coordinate projection and quotient, or the maximum
element order and a cyclicity comparison.

Tests check small group laws, enumerate orders and exponents for factor sizes
2–4, verify torsion counts and projection kernels, and check the cyclicity
criterion across the full parameter range. Fixed seeds check reproducibility
and variety.
