# Generalized quaternion groups

Groups Q_n of order n ∈ {8,16,32,64,128,256}, using the normal form r^i s^j.
Three views emit products and inverses, a conjugacy class and center, or the
four powers of an element outside the cyclic subgroup ⟨r⟩.

Tests exhaust group axioms for orders 8 and 16 and check inverses, minimal
orders, centers, the unique involution, and presentation relations throughout
the range. Fixed seeds check all six orders and reproducibility.
