# Symmetric groups

Uniformly shuffled permutations in S_n with 3 ≤ n ≤ 9. Four views emit the two
composition orders of a pair, a cyclic subgroup and sign, a conjugate, or the
image of a subset. Cycle notation and one-line notation serve separate views.

Tests check composition direction, exhaustive S_3 group axioms, cycle
reconstruction, inverses, minimal orders, inversion-count parity, and parity
multiplicativity across every degree. Fixed seeds check reproducibility and
variety.
