# Symmetric groups

Original bounded procedural material for S_n, with n uniformly chosen from
3 through 9 and independent uniformly shuffled permutations p and q. Every
output defines its notation and composition convention and gives an exact
product, inverse, cycle decomposition, order, and parity. Fixed points are
omitted in cycle notation but counted when computing order and parity.

Reference checked: J. S. Milne, *Group Theory*, v4.01 (November 6, 2025),
[permutation groups, pp. 64–69](https://www.jmilne.org/math/CourseNotes/GT.pdf).
The reference supports the mathematical definitions; no dataset or text was
downloaded into this leaf or copied into its output. Milne's notes are licensed
CC BY-NC-SA 4.0; this generator independently implements the mathematical facts.

Tests check the composition convention, exhaustive S_3 group axioms, and 128
seeded samples for every supported degree against cycle reconstruction, inverse,
minimal element order, inversion-count parity, and parity multiplicativity.
