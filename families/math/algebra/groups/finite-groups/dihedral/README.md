# Dihedral groups

D_n = ⟨r,s | r^n=s²=e, srs=r⁻¹⟩ for 3 ≤ n ≤ 48.
Four views emit multiplication in normal form, a conjugacy class and center,
the induced permutation of polygon vertices, or an element's centralizer.

Tests exhaust group axioms through n=8, check inverses, minimal orders, and
centers throughout the range, and verify that the polygon action respects
multiplication through n=12. Fixed seeds check reproducibility and variety.
