# Finite cyclic groups

Additive groups Z/nZ with 2 ≤ n ≤ 96. Four views emit a generated subgroup,
a quotient map and kernel, a multiplication endomorphism's kernel and image,
or a full addition table (2 ≤ n ≤ 9, sampled with probability 1/32).

Tests exhaust group laws through n=16 and check element orders, generated
subgroups, divisor subgroups, quotient maps, and endomorphism kernels/images
through n=96. Fixed seeds check reproducibility and variety.
