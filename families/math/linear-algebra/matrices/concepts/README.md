# Matrix concepts

25 records of canonical identities and concrete matrix calculations, covering
spectra, similarity, rank, orthogonality, determinants and counterexamples.
Records retain their IDs and source provenance. Definitions and explanatory
paragraphs have been replaced with the equations or examples themselves.

The recorded references are Gilbert Strang's MIT 18.06/18.06SC lecture summaries
on multiplication, transpose, subspaces, determinants, eigenvalues,
orthogonality, symmetry, similarity and singular value decomposition. Exact
source URLs remain in each record's provenance. These records contain factual
notation and independent calculations; source prose is not reproduced.
