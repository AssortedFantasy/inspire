# Inner product spaces

One procedural leaf, [orthogonal projections](orthogonal-projections/README.md),
emits exact rank-one orthogonal projections in R^3: a rational matrix, a
projected integer vector, an independent kernel basis and spectral identities.
There are no corpus records in this branch.

The generator uses bounded integer directions and vectors with the standard
dot product. Its leaf notes document arithmetic bounds, sampling and the
primary mathematical reference.
