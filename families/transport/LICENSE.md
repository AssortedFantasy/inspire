# OurAirports data

Source: https://ourairports.com/data/

OurAirports releases all data to the Public Domain. The source states that it
comes with no guarantee of accuracy or fitness for use. Credit is appreciated
but is not required.

Inspire embeds selected airport, country and landing-surface metadata from
OurAirports revision b529623d2a0b09a9be78d37fc7a7a5e1e16e3451 (2026-10-16).
Fields are joined, filtered, grouped by airport type and formatted as documented
in transport/README.md. Images, user comments and site prose are excluded.
