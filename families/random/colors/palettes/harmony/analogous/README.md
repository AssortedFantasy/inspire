# Analogous palettes

Five HSL swatches follow a 40–80° hue arc, with shared saturation (40–75%)
and lightness (38–65%). The central hue is uniform across integer degrees;
adjacent spacing is uniform from 10° to 20°. This gives coherent neighboring
hues without nearly neutral or nearly black swatches.

Tests cover every hue rotation and spacing, emitted parameter ranges,
seeded coverage, and distinct swatches after RGB byte rounding. HSL lightness
is not perceptual brightness; these palettes carry no accessibility claim.
