# UUID

Canonical lowercase UUID version 4 with the RFC variant bits set. The remaining
122 bits come from Inspire's supplied seeded RNG. This is reproducible stimulus
data, not a security token or a guarantee of uniqueness across repeated seeds.

Format reference: [RFC 9562, sections 4 and 5.4](https://www.rfc-editor.org/rfc/rfc9562.html#section-5.4).
