# Dates

Uniformly samples a calendar day from 1600-01-01 through 2199-12-31 and a second
within that day. Five formats use month names, an explicit year/month/day label,
or ISO-style ordering. All times are UTC; no local timezone or daylight-saving
rules are implied. Uses the proleptic Gregorian calendar, including before its
historical adoption in some regions. Leap seconds are excluded.

Calendar rule reference: [US Naval Observatory](https://aa.usno.navy.mil/faq/calendars).
