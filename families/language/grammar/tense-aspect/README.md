# Tense and aspect

Six original editorial examples illustrate English progressive and perfect
constructions. This small, coherent leaf is not a comprehensive grammar or a
downloaded corpus. Provenance identifies the sentences as invented and avoids
claims about all dialects.

## Complete review (2026-10-13)

All 6 records were read in full, including their labels, examples, explanations,
and provenance. Each emits self-contained material rather than an assignment.
All original IDs and example sentences are retained.

| ID | Substantive check |
| --- | --- |
| `present-progressive` | `is repairing` gives a present activity in progress. |
| `past-progressive` | `was repairing` supplies background for `began`; stopping is not asserted. |
| `present-perfect` | `have misplaced` links a prior event to the stated present consequence. |
| `past-perfect` | `had departed` precedes the stated past arrival. |
