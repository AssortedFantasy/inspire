# Conditionals

Four original editorial records: open, remote and past counterfactual
conditionals, and an unless clause. These are invented
examples, not downloaded corpus sentences or quotations.

All five original examples and explanations were read individually. The remote example's
explanation now distinguishes hypothetical present reference from past time and
identifies the ability meaning of could. Original IDs and example sentences are
preserved. The wish is a desiderative complement rather than a conditional;
it was relocated intact to the complementation leaf.

Checked against the British Council's explanations of
[open and remote forms](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/conditionals-zero-first-second)
and [past counterfactual forms](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/conditionals-third-mixed).
References support the review; no source examples were copied.

Validation: exact id/text/provenance schema, four nonblank unique IDs, four
nonblank unique texts, no NUL characters, and nonblank editorial provenance.
Each emitted record contains its own construction label, example and explanation.
