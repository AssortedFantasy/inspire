# Information structure

Six original English examples with construction labels and explanations:
it-cleft, wh-cleft, object fronting, negative inversion, locative inversion,
and extraposition with anticipatory *it*. Each record is self-contained.
These illustrate ways of arranging emphasis and information; they are not a
downloaded corpus or claims about every English dialect.

All six records were read individually in the 2026-10-13 review. The wh-cleft
explanation now identifies the focused noun phrase after *is* explicitly,
avoiding the original wording's implication that it is a second clause.
All examples and stable IDs were retained. The fronted object has no resumptive
pronoun; negative inversion places *had* before *I*; locative inversion places
the subject after *stood*; extraposition uses nonreferential *it*.

The review checked the analyses against Cambridge's
[cleft sentences](https://dictionary.cambridge.org/grammar/british-grammar/cleft-sentences),
[fronting](https://dictionary.cambridge.org/us/grammar/british-grammar/fronting),
[inversion](https://dictionary.cambridge.org/grammar/british-grammar/inversion),
and [anticipatory it](https://dictionary.cambridge.org/grammar/british-grammar/it%7C).
The broader grouping follows the constructions discussed under
[information structure](https://www.cambridge.org/highereducation/books/a-students-introduction-to-english-grammar/EB0ABC6005935012E5270C8470B2B740/information-structure/8F20810C6195C482469059E2C96E6093).
References support the analysis; the sentences remain original editorial
examples, as recorded in provenance. No source wording was imported.

Validation: six records with exactly `id`, `text`, and `provenance`; nonblank
strings, no NUL characters, six unique IDs, and no duplicate emitted text.
