# La Fontaine, translated by Elizur Wright

241 whole fables and reviewed consecutive excerpts from the pinned public-domain
1882 edition of Wright's 1841 translation, Project Gutenberg 7241. Source URLs,
checksums and rights are in `families/literature/sources.json`; the embedded notice
is `families/literature/LICENSE.txt`.

Replay with `python -B families/literature/import_data.py --check` using the cached
source in `target/imports/literature/pg7241.html`. In addition to HTML note links,
the importer removes bracketed numeric footnote references printed as plain text
inside this edition's verse blocks. Notes are omitted, so their reference numbers
would otherwise dangle in the sampled fables. Verse wording and line order remain
unchanged.
