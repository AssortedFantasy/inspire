# Mechanisms

Concise descriptions of mechanical advantage, linkages, oscillators, fluid
behavior, and feedback control. Each record includes a source URL in provenance.
Idealized principles state their relevant assumptions; examples describe how a
mechanism works rather than directing the reader to build one.

Sources include NASA and NIST explanations, OpenStax physics, Ohio University
kinematics notes, APMonitor control lessons, and original siphon experiments.
