# Bridge deals

A uniformly shuffled standard deck is partitioned into four distinct 13-card
hands. Output sorts suits S/H/D/C and ranks high to low; a dash denotes a void.
High-card points are A=4, K=3, Q=2, J=1, totaling 40 across the deal. No bidding,
contract, vulnerability, dealer, or result is asserted. Original code and text.
