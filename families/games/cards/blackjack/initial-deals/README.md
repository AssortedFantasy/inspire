# Blackjack initial deals

Single standard deck without replacement, dealt player/dealer/player/dealer.
Only the dealer upcard is exposed. Player totals use ace=1 or 11 and ten-valued
face cards; natural means an ace and a ten-valued card in the initial two cards.
No hit/stand strategy, dealer action, payout, or outcome is asserted. Original
code and text; house rules do not enter this limited initial-deal object.
