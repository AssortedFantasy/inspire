# Five-card poker

Uniform five-card subsets from one shuffled standard 52-card deck; no jokers.
Ranks implement ordinary high poker, including ace-low straights. Categories
and ordered tie-break ranks are printed; suits never break ties. This is a hand
sampler, not a betting simulation. All text and code are original.
Reference: [Bicycle poker rules](https://bicyclecards.com/how-to-play/poker).
