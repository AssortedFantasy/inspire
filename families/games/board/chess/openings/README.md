# Opening book

Exact named PGN endpoints from pinned Lichess chess-openings, CC0 1.0.
See `../../../README.md` and `../../../openings-source.json` for the import and
hash manifest. `LICENSE` contains the complete upstream CC0 notice.
All 3,865 source rows are retained. These are opening-book lines, not recommendations
that every move is best. Variations are never cut short.
