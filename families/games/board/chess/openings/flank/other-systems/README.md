# Other flank systems

Exact Lichess names and complete move sequences remain unchanged. Named systems
are separated below fianchetto attacks, knight openings, wing-pawn openings, and
restrained-center openings. A named system can begin with a transposing move
order; its source name, rather than only its initial move or ECO code, identifies
the family. Equal local weights balance systems rather than record counts.

Unusual openings and gambits are historical named lines, not recommendations for
strong play. Identical source names can identify distinct complete move sequences.
