# Reversi positions

Original random legal playouts from the standard four-disc center. Every placed
disc brackets and flips opponent discs; a pass is forced only when no move exists.
The game ends when neither side can move, including positions with empty squares.
Printed histories include passes; next moves and terminal disc-majority results
are explicit. Sampling is trajectory-biased and does not imply optimal play.
Reference: [World Othello Federation rules](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english).
Only original literal rules summaries and generated positions are embedded.
