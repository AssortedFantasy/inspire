# Connect Four positions

Original random legal playouts on the classic 7-column, 6-row board. Each token
falls to the lowest empty cell; the first contiguous four ends the game.
Histories reconstruct the printed state. A full board without a winner is a draw.
The target ply count and legal columns are sampled uniformly, not board states.
Reference: [Hasbro classic rules](https://www.hasbro.com/common/documents/dad2614d1c4311ddbd0b0800200c9a66/DE3C8F8050569047F5AA9FBB9F16909B.pdf).
No publisher prose, imagery, or trademarks artwork is embedded.
