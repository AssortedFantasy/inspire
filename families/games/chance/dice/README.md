# Dice

Original simulated dice results: sums with signed modifiers, keep-high/low rolls,
explicit success-counting pools, four balanced ternary dice, percentile dice, and
opposed sums. Each face is sampled uniformly and independently. Pool and opposed
parameters are given by compact notation; these are generic constructions, not claims to
implement a particular role-playing game's rules. Percentile 00 with 0 is 100.
No rerolls or unbounded explosions.

The balanced ternary distribution matches the faces described by the officially
endorsed [Fate SRD](https://fate-srd.com/fate-core/what-you-need-play); output uses
standard `4dF` notation and does not include other Fate rules or text.
