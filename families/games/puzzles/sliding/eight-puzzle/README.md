# Solvable eight-puzzles

Original 3x3 puzzles generated by 20-80 legal blank moves from the standard
solved board, avoiding immediate reversals. If a walk returns to the goal, one
additional legal move ensures a puzzle is shown. Tests replay every scramble and
check even inversion parity. Samples are not uniform over solvable states and
scramble length is not a difficulty or shortest-solution claim.
