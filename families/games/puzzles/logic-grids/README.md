# Logic grids

Original bijection puzzles on three or four ordered positions. Samples use two
item categories, or three categories on three positions, with delivery, recital,
and shop settings. A category uses every position exactly once. Clues mix fixed
positions, associations, exclusions, order, immediate order, and exact distance.
The ordering direction is printed with each puzzle; solutions are omitted.

All 36, 216, or 576 possible assignments are enumerated. True clues reduce that
set to the sampled answer, then a deletion pass removes redundant clues. The
remaining set is irredundant, not necessarily globally smallest. Tests enumerate
every answer and every single-clue deletion across all three sizes.

[Puzzle Baron's logic puzzle description](https://jigsaw.puzzlebaron.com/puzzles.php)
is a reference for the category-matching format. No source puzzles or prose are
copied. There is no asserted human difficulty rating.
