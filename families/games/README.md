# Games

- `dice`: single dice, sums, retained dice, pools, ternary dice, percentile dice,
  and opposed sums; all resolution rules are explicit.
- `sudoku`: original 9x9 puzzles with rotationally symmetric clues and a proved
  unique solution; bounded generation, no claimed difficulty rating.
- `tic-tac-toe`: reachable positions with move histories and game status.
- `chess-openings`: a curated opening book with standard numbered notation,
  names and ECO codes; not an engine generating arbitrary chess games.

Leaf READMEs document rule references, provenance, and sampling limitations.
