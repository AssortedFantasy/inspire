# Systems

Synthetic mechanisms with computed witnesses: stationary queue distributions,
population equilibria and Jacobian spectra, exact fault-tree cut sets and
probabilities, complete critical-path schedules, and feasible maximum flows
paired with minimum cuts.

The family has local weight 2. Its five branches have equal weight so that the
different model structures remain visible. Each leaf first selects a structural
regime, including ordinary cases alongside saturation, invasion thresholds,
shared failures, tied critical branches, and capacity changes with zero marginal
throughput. Sources, model assumptions, numerical limits, and independent
invariant tests are documented beside each generator.

All computations are bounded and use only the supplied RNG. No network access,
external data, empirical claims, or added dependencies are needed at runtime.
