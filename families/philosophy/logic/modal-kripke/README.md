# Kripke frames

The relation prints one successor set `R(w)` for every world, including dead
ends. This keeps dense frames readable without repeating the source world for
every edge. Invalid axiom checks define the displayed formula as `φ` once and
identify the counterexample world with that symbol.

Random binary nodes have distinct syntactic operands. A collision swaps `p`
and `q` throughout the right operand, preserving shape and depth in bounded
time. Explicit axiom constructors retain their intentional repeated
subexpressions. Frame sampling and modal semantics are unchanged.

Tests check random operand distinctness, compare independent world and set
evaluators, and exhaust the axiom correspondences on all frames with at most
three worlds.
