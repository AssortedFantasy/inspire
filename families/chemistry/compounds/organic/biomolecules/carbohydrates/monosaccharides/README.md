# Monosaccharides

Aldoses and ketoses form separate branches, with carbon-count subdivisions where
represented. These are neutral, unmodified sugars; deoxy sugars, amino sugars,
sugar alcohols and sugar acids belong to sibling derivative branches.

D/L labels describe configuration, not optical rotation. Source structures can
be open-chain or cyclic; unspecified anomeric centres must remain explicitly
unspecified in descriptions. A single PubChem representation does not describe
every form present in solution. Original D-glucose (CID 5793), D-fructose
(CID 2723872) and D-ribose (CID 10975657) identities are retained.

Import with `python -B import_data.py --download` during development, then without
`--download` for byte-identical offline regeneration from pinned cached sources.
Child manifests identify exact URLs and SHA-256 response digests. Data scope is
factual identity and computed properties; each record credits PubChem/NCBI/NLM.
Contributed PubChem material may carry separate rights; no third-party prose is
imported. See the primary NCBI reuse policy:
https://www.ncbi.nlm.nih.gov/home/about/policies/.
