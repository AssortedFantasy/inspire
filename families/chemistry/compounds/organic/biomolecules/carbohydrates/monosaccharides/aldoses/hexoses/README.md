# Aldohexoses

Sixteen selected D/L identities: allose, altrose, glucose, mannose, gulose,
idose, galactose and talose. Open-chain and pyranose representations are sampled
separately. Cyclic anomeric centres here are unspecified. The selected CIDs
do not enumerate all solution forms. Sources and deterministic transformation
are maintained in the parent aldose importer and manifest.
