# Archive

Historical research, planning notes, content audits, and agent review artifacts.
These files are retained as project history, not current maintenance instructions.
Commands, paths, counts, and review status may reflect an earlier checkout.

- `REASEARCH.md`: research notes from October 4, 2026; original filename retained.
- `INSPIRATION_SUGGESTIONS.md`: proposals and integration notes from October 2026.
- `content-audit.md`: historical content changes and verification reports.
- `families/`: former review manifests, agent queues, and handoff instructions,
  preserving their original paths below the family tree.
- `scripts/check_reviews.py`: retired checker for those review manifests.

Current human feedback is in [docs/reviews](../reviews/human-feedback.md).
